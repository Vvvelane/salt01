# 05 — Position / Accounting

信号、目标仓位、订单、fill 和实际仓位是不同对象。只有真实记录的 fill（以及明确登记的合约/结算事件）能改变账本。撤单、拒单和未成交信号不能改变 position。

对合约 c，在没有其他明确头寸调整事件时：

`q_after(c) = q_before(c) + Σ signed_fill_quantity(c)`。

买入数量为正、卖出为负，反手自然拆成平旧仓与开新仓的数量；不能丢掉其中一段费用。每个 fill 有唯一 ID、订单 ID、合约、时间、方向、数量、价格和费用。重复回放必须幂等或明确拒绝，不能重复记账。手数、乘数、价格单位、计价币种和货币精度必须显式声明。

基本单合约损益（固定乘数 m、同一币种、相邻两个估值点间无特殊结算/合约事件）：

`gross_pnl = q_previous × m × (mark_now - mark_previous) + Σ[fill_qty × m × (mark_now - fill_price)]`

`net_pnl = gross_pnl - costs`

`equity_now - equity_previous = net_pnl + net_external_cash_flow`

上式可作为未来事件账本的独立对账基准，不是本阶段实现。多合约逐合约求和，跨币种需明确当时可知 FX 及其损益。costs 包含按政策登记的费用；返佣等负费用必须有显式类型。买卖价差若已体现在 fill_price 中，不得再次重复扣除。

期货逐日盯市、现金划转、未实现/已实现 PnL 的定义要在具体会计政策中冻结：结算重置成本基准同时调整现金，不能再额外增加一份权益。平仓后 mark 变化不能继续产生持仓损益。期末未平仓不凭空平仓，最终估值和未实现 PnL 单独披露。

保证金不是买入资产的本金费用；占用、可用资金、权益分别记录。换月视作具体合约的平/开交易并承担费用；主连跨合约跳变不能直接记为持仓损益。

每次运行保留初始状态、fill 账本、估值事件、最终状态与对账残差。精度容忍度按币种和数值方法事前规定，不能为了通过对账而事后放宽。
