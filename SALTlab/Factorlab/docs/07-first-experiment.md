# 07 — 第一条实际研究链（后续任务）

1. 从 Registry 选择一个单一 Idea 或一个依赖清楚的组合，记录竞争解释与证伪条件。先检查 `source_gaps`、待定工程角色和原文范围；当前不预选具体策略。
2. 在排名前十的少数品种/具体合约和短窗口上读真实 OHLCVA，记录数据文件与时间范围。评估其字段是否足够支持 Idea；OI/元数据需求不能冒充只有 OHLCVA 即可。
3. 明确 factor 公式、参数、warm-up、输入截止/可用时间和无效原因。先做特征与独立 forward label 的信息检验，并编写截断不变性测试。
4. 填写 `configs/experiment.template.json`：研究目标、数据快照、样本划分、基准/对照、参数与冻结的信号映射。测试后任何择向/调参视作新版本。
5. 针对这个实验冻结 signal timing、entry、exit、latency、fill、sizing、成本、日历和会计政策。给出具体时间的正反例；检查 invariant 清单。
6. 只实现这条链需要的最小执行/记账能力。用合成成交路径验证数学守恒，再对小份真实数据对账。未通过对账不发布绩效。
7. 留存成功和失败运行，区分信息检验、gross/net、成本敏感性、样本内外和数据限制，再决定下一步扩展。

本阶段不依赖额外软件、服务器、域名或部署。未来 public demo 从已验证产物另行导出少量数据；本地研究文件、机器路径和全量行情不随展示系统自动发布。
