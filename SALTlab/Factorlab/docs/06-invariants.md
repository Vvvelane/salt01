# 06 — Backtest Invariants

本表约束未来人工/Agent 实现。本阶段仅建立规范；对应引擎测试要在功能实现时加入，不能宣称已经验证尚不存在的撮合或会计逻辑。

| ID | 不可违反的条件 | 未来最小反例/验证 |
|---|---|---|
| CAU-01 | 所有影响决策的信息均已可知 | 修改未来价格、volume、Universe，不改变历史决策 |
| CAU-02 | 特征和未来标签隔离；fit 只用约定过去窗口 | 测试期极值不改变训练归一化器；禁止 bfill |
| TIM-01 | 四时间偏序成立，fill 不早于 executable time | 使用 09:00 bar close 却在 09:00 open 成交必须失败 |
| TIM-02 | 日历、session 和同时间事件顺序显式 | 周五夜盘、节假日、午休、同边界可用/下单 |
| DAT-01 | 无效/缺失与真实 0 值分开，不静默填补 | 零方差、零成交、缺 bar、NaN/inf 输出原因 |
| DAT-02 | 唯一性按合约+频率+源时间定义，顺序确定 | 同时间多合约合法；同合约重复行不能静默择一 |
| EXE-01 | 信号/订单不等于成交；未成交不改变仓位 | 拒单、撤单、部分成交分别回放 |
| EXE-02 | Fill 有支持它的价格、时间和执行政策 | OHLC 同时触及止盈止损不择优；限价触及不保证成交 |
| EXE-03 | 数量与费用按真实 fill 逐笔计算 | 半量成交、反手、单腿失败，不能按目标数量记收益 |
| POS-01 | 仓位变化等于 signed fills 加显式调整 | 买 2、卖 3 后净仓 -1；无 fill 仓位不变 |
| ACC-01 | 权益变化=净损益+外部净现金流 | 多空、平仓、反手、期末未平仓逐事件对账 |
| ACC-02 | 费用只计一次，结算不创造权益 | 常价往返只损失明确成本；结算现金/未实现重分类守恒 |
| ACC-03 | 换月不是免费收益；合约单位不能猜 | 两合约不同价格的切换只产生实际持仓损益与交易成本 |
| ACC-04 | 无持仓且无交易时 mark 变化不产生交易损益 | 平仓后后续涨跌不改变交易 PnL |
| REP-01 | 同输入/版本/随机种子产生同事件序列 | 重放一致；重复 fill ID 拒绝或幂等；失败状态保留 |
| EVA-01 | 评价消费已对账结果，不重写输入与交易 | 删除亏损/失败事件、测试后翻号均视为新实验 |
| EVA-02 | 预测标签收益与可执行净收益明确区分 | factor IC/forward return 不能标成 strategy PnL |

未来实现遇到未冻结政策时，停止该执行路径并列出缺失项；仍可进行独立的数据读取或因子信息检验。政策变更必须版本化，并说明影响哪些 invariant 测试。上述数学红线不预先选择某一种 entry、exit、latency 或 sizing 方案。
