# 06 — Data and Costs

行情只通过 `saltcore.read_bars(..., kind="main", freq="1min")` 读取。Factorlab 不保存第二份行情，
不重新选择主力、不重建复权，也不读取近远月腿。`roll_flag` 来自主连中合约代码的变化；单 session
构造不跨该变化。

`config/instruments.json` 保存当前研究使用的乘数、tick、手续费和 session。历史手续费、历史夜盘
制度和精确涨跌停价并未逐日复原，因此 `metadata.json` 明确把它们标作当前规则情景。

少量 1min 缺失或无效时，只跳过该观测及依赖它的窗口，不排除整个 session，也不会报错。预定
开盘或收盘边界缺失仍记录在 `metadata.json`，但只是诊断项。完全缺失的分钟没有人为补价，因此
按观测行定义的窗口可能略长于墙钟时间。

当前临时规则把出现任一有效平 OHLC bar 的 trading date 整体视为无效数据日，不形成信号或成交。
它没有使用已有日度涨跌停表，可能同时排除普通低波动分钟；这是第一版明确接受的近似。

warm-up 交易日从该交易日的真实 session 起点读取：有夜盘时从前一个交易日 21:00 开始，无夜盘
时从当日第一个日盘 segment 开始。报告区间仍为 `[2016-09-08, 2026-09-08)`；前置数据只用于
480 根波动率与逐品种缺口常数。
