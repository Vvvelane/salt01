# 02 — Causality

bar 标签是该分钟开始时刻；其完整 OHLCV 只在该分钟结束后可知。特征最多使用当前已完成 bar，
交易最早发生在下一根 bar 的 open。波动率只使用截至上一根 bar 的有效 session 内收益，不使用
centered rolling、负向 shift、bfill 或全测试样本归一化。

收益不跨 day/night session，也不跨主力合约代码变化。交易日锚定版本的 `g` 在报告期前逐品种
估计并冻结；新上市品种没有报告期前样本时，先留出最早的测量区间，测量区间不计入 PnL。夜盘
尚未发生的夜收→日开缺口不能提前进入夜盘信号。

本版使用当前 session 规则回放历史，并使用今天已选定的 research11。结果是明确的研究情景，
不声称还原历史时点的制度或当时可投资 Universe。

“一天内出现任一平 OHLC 就整日排除”是回测前的数据质量筛选，会用当天稍后才能观察到的信息
排除当天更早的 bar，因此不能解释成实盘当时已经知道该日不可交易。它是用户为第一版冻结的保守
研究样本政策；接入逐日涨跌停数据时必须替换，不能继续把它称为因果执行模型。
