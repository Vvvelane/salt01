# 04 — Execution

当前只有 `signal_close_next_bar_open`。数量固定一手，滑点固定 0 tick，费用按品种配置逐边扣除。
不加仓，不在一次信号事件中反手。主力连续数据里的 `contract` 必须与信号来源一致；若持仓期间
合约已经改变，程序不能用新合约价格假装平掉旧合约。

已保存的上一版十年结果曾允许尾盘锁住后等待旧合约下一次可交易 open，相关 173 笔记录保存在
`issues/delayed-exits-v3-10y.*`。当前临时政策在回测前排除所有含平 OHLC 的 trading date，因此
新运行不会在这些数据日形成仓位；旧合约懒加载仍作为未预见执行缺口的账本保护。

所有策略在所属 session/交易日收盘前 5 分钟进入共享平仓窗口。窗口内首个可交易 open 平仓并
禁止新开仓；这是执行边界，不是 factor 参数。

缺少少量分钟，包括配置的开盘或收盘边界，不再排除整个 session。不存在的分钟不成交，相关
窗口跳过该观测；收盘前五分钟内只要仍有可交易 open，执行层就会提前完成 scope 强平。

无效 OHLC 或 volume≤0 的单分钟不成交。平 OHLC 不再只处理该 bar：整个 trading date 被当成
数据无效日。它不等于已准确识别涨跌停。

FID004 的结构 stop 是唯一 bar 内执行规则：open 已越过 stop 时按 open，bar 范围首次包含 stop
时按 stop。没有分钟内路径可供优化，因此不会在同一 bar 内选择更有利价格。账户级 `risk_cap`
没有数值且本版不做总风险，所以不执行这项过滤。
