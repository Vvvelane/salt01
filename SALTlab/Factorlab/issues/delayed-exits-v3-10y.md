# intraday-v3 十年结果：173 笔延迟退出

## 状态

这是 2026-09-13 已完成的十年运行结果，保留用于审计当时的执行规则。对应的 173 笔交易已经
冻结在 [delayed-exits-v3-10y.csv](delayed-exits-v3-10y.csv)，原始完整交易仍在各 Factor 的
`runs/v3_10y/<strategy>/<product>/trades.csv`。

这次运行把有效但 OHLC 四价相同的分钟视为暂时不可成交。若 scope 强平窗口内持续不可成交，
仓位保留到原合约下一次可交易 open，因此产生 `forced_scope_close_delayed`。这不是策略主动选择
跨 session 持仓。

之后冻结的新临时数据政策已经改为：只要某个交易日出现有效的平 OHLC bar，整个 trading date
不参与信号形成和成交。为了保留本次已完成结果，修改政策后没有重新运行十年回测；未来重跑会
形成新的结果版本，不能把它与这里的 173 笔混为同一次实验。

## 已核对的例子

- `FID004_day_v3 / AG2006.SHF`：2020-05-18 10:08 以 4201 开多，14:55 开始强平但尾盘持续
  4201 平 OHLC；日度表确认当日涨停价是 4201，最终在 21:00 以 4207 平仓。
- `FID004_day_v3 / JM2509.DCE`：2025-07-31 10:47 以 1057 开空，尾盘持续 1045.5 平 OHLC；
  日度表确认当日跌停价是 1045.5，最终在 21:00 以旧合约 1045 平仓。
- `FTR001_rolling_30m_v3 / P2005.DCE`：2020-02-28 14:35 以 4952 开空，14:55 后触及当日
  4948 跌停，周末后于 2020-03-02 09:00 以 4952 平仓。
- `FTR001_trading_day_v3 / JM2501.DCE` 与 `RB2501.SHF`：都在 2024-09-27 夜盘开多，
  2024-09-30 尾盘分别封在真实涨停价 1546 与 3551；再遇国庆休市，直到 2024-10-08 09:00
  才能平仓，从入场到退出约 251 小时。

这些跨日仓位不符合策略希望的 holding scope，但符合当时的记账原则：失败的退出不能让已经存在
的仓位凭空消失。日度涨跌停表只能验证价格是否触及限制，不能证明当时排队能否成交；完整 173 笔
尚未逐笔用涨跌停表分类。
