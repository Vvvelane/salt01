# 附录 A：组 1 / 组 2 的 27 个 idea 如何进入研究系统

本附录审阅 [组 1 原文](../factor_research_group1_trend_reversal.md) 与 [组 2 原文](../factor_research_group2_volatility_activity.md)，保留经济 idea，重新规定研究角色、时间尺度及可证伪实验。这里是实施建议，**没有运行回测，也没有认定任何候选有正收益**。原文列出的文献来源仍需按主计划的文献核验流程复核；尤其不能把文献原市场、原频率的发现直接视作中国商品期货日内证据。

## A1. 阅读方法与统一约束

- `alpha`：候选方向预测，必须对未来可交易价格收益做样本外检验。
- `state`：趋势效率、参与度、市场环境等条件信息；只有证明对基准的增量价值，才进入仓位函数。
- `risk`：估计持仓风险和配置风险预算；有效不等于能预测涨跌。
- `execution`：资格、容量、流动性及成本分层；没有盘口时属于代理或情景模型。
- `P0`：基础合同、风险/执行与状态组件的数据接口；`P1`：已冻结的首批 alpha 实验；`P2`：后续候选及增量扩展。与主计划使用同一优先级，优先级是研发顺序，不是预期收益排名。

**首批名单与参数以 [first_experiment_specs.md](first_experiment_specs.md) 为唯一实验合同，本表未被选入的窗口都是后续候选，不能自动扩充本轮参数搜索。** 表中的 formation 是观测信息窗口，holding 是固定期限标签/简化交易的观测范围，不是优化后参数。日内分钟均指可交易分钟，不把午休计为交易时间；同时报告墙钟持有时长。`session` 指日历元数据里明确定义的整段夜盘/日盘，`segment` 指其中连续交易片段，不能用自然日期替代交易日。任何跨休市间隔的收益必须标明是否纳入。

先固定少量经济上可解释的时间尺度，再在训练期看收益衰减曲线，最终用验证集锁定一个版本；测试集不再选择窗口。不要把下表所有 formation 与 holding 做全笛卡尔搜索，也不要将每一个窗口包装成新的独立 alpha。

每条研究同时保存 `feature_asof`、`available_at`、`decision_at`、`earliest_fill_at`、具体合约、calendar 版本与数据 manifest。`available_at <= decision_at < earliest_fill_at` 是默认时序，即时日内信号以已完成 bar 产生，首批使用 `1min.bar_start > decision_ready_at` 的第一根可交易 bar；已提前生成的时间订单沿首批合同允许在预定边界尝试成交。另做额外一根 1 分钟 bar 延迟的敏感性实验。上一分钟 close 与下一分钟 open 同时间边界并不意味着数据可零延迟获得。

## A4. 先修正哪些明确问题

以下是从文档内部即可发现的定义冲突或逻辑问题，不依赖“回测不好”来判定。

1. **公式、事件与仓位必须分开。** FTR004 的通道位置、突破事件、持续持仓是三个对象；FRV005 的 RSI 连续值和回穿事件是两个对象。`FeatureSpec → HypothesisSpec → PolicySpec` 分开版本化，禁止从 factor 列名猜仓位。
2. **修复 signed conditioner 翻向。** FRV003、FVO007 原文已指出乘积符号问题，新 registry 只能把无符号 conditioner 应用于明确 base direction，或显式登记交互回归。旧连续式可保留为审计对象，不能被默认 loader 当目标仓位。
3. **统一 raw change 与 standardized surprise。** `doi<0`、`z(doi)<0`、`z(ΔOI)<0` 不是一回事。FRV002 的 log-volume deviation 与 z 阈值也不能混用。字段名写清 `*_raw`、`*_z`，schema 加单位与变换版本。
4. **单位检查。** ATR 的价格单位与 ATR/price 的无量纲单位分离；收益波动与每手货币 P&L 波动分离；volume 和 amount 代理分离。货币风险示例：`cash_pnl = contracts × multiplier × price_change`，具体合约乘数必须取该日期有效版本。
5. **描述统计不等于预测显著性。** FTR006 斜率 t 值不应在 UI 标成“95% 趋势置信度”；ER 不能标成“趋势成功率”。检验对象是随后可执行收益的样本外分布及增量。
6. **中性指标不等于盈利平仓。** FRV001 滚动收益冲击消失、FRV004 z 归零、FRV005 RSI 回到 50 均可能对应亏损。UI 同时展示指标退出原因和实际 P&L，不能命名为固定“止盈”。
7. **完整日与当前已知前缀分开。** 完整日 RV、日最高最低、当日总量不能在开盘拿来筛选。当前时点累计 RV/区间量可用，但命名与预测期限必须匹配。

另一些是**待验证假设而非已证实 bug**：高 ER 能增强趋势、高成交量能增强反转、退出 deadband 降低总成本、ATR 止损改善风险收益、30/70 回穿优于直接反转、低 OI 组有更高净反转收益。不能因为“看起来更稳健”就直接放进生产规则。

## A5. 日内首轮的具体 apply 流程

### A5.1 最小实验集合

首批严格采用主合同的四个实验：`OPEN_TO_TAIL_V1`（FID001/FID003 的竞争解释，由组 4 提供源 idea）、`ORB_CONT_V1`（FID004/FTR004）、`PRESSURE_REV_V1`（FRV001/FRV004）、`DAILY_TREND_V1`（FTR001）。基础组件为 `RV_SCALE_V1` 与 `ACTIVITY_STATE_V1`；它们不是额外 alpha。FRV006 的 `night_to_day`、独立日内收益趋势及 FTR006/FTR007 路径质量条件均放在 P2 后续清单。

**一次只新增一个信息来源。** 基准与条件版本使用完全相同的合约选择、决策时点、持有期限、可交易样本、成本与风险预算；否则“增强”可能只是选择了另一类市场或少交易带来的表象。

### A5.3 因子与组合的连接

先把不同特征归为经济假设 family，再分配 family 风险预算：多个均线/MACD 同时做多同一品种，不代表多个独立看多理由。趋势和反转在同一合约同一时刻相反时，保留各自 shadow P&L 以评价 idea；真实订单在组合层净额化，并把实际节省/产生的费用归因清楚，不能把两份独立回测的收益直接相加。

跨期限也不能仅凭“日内与日频”就认定分散：快速趋势和慢趋势在大行情中可能共用商品方向与行业暴露。新增子组合必须证明在统一成本与风险约束下改善组合，而不仅是单独收益为正。日内不主动隔夜是策略目标；锁板、休市或未成交造成的实际残仓必须延续入账，不能在 session 边界删除。

最终首版展示的是“idea → 可知信息 → 可交易预测 → 风险/执行 → 样本外结论”的证据链。27 个名称不需要变成 27 条持仓策略；保留有效的少数方向 family、可靠风险估计与有增量的条件信息，已经是完整而有研究价值的产出。
